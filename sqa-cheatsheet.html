Cheatsheet

The shape of a query

SELECT   columns or calculations
FROM     table
JOIN     other_table ON matching_condition
WHERE    row filter
GROUP BY grouping columns
HAVING   group filter
ORDER BY sort columns
LIMIT    how_many;

You write it in this order. The database works it out as FROM, JOIN, WHERE, GROUP BY, HAVING, SELECT, ORDER BY, LIMIT. That is why a SELECT alias cannot be used in WHERE.

Filtering

WHERE a = 1 AND b <> 2
WHERE x BETWEEN 1 AND 5      -- inclusive
WHERE city IN ('A', 'B')
WHERE name LIKE 'S%'         -- starts with S
WHERE city IS NULL           -- never = NULL
WHERE NOT (a = 1 OR b = 2)

Summaries

COUNT(*)  COUNT(col)  COUNT(DISTINCT col)
SUM(x)  AVG(x)  MIN(x)  MAX(x)
SELECT g, COUNT(*) FROM t
GROUP BY g HAVING COUNT(*) > 5;
round(100.0 * a / b, 1)      -- percentage

Joins

INNER JOIN  matches only
LEFT JOIN   all left rows + matches
-- find the unmatched:
FROM a LEFT JOIN b ON b.a_id = a.id
WHERE b.id IS NULL
CROSS JOIN  every pairing
-- self join: two aliases of one table

Subqueries and sets

WHERE x > (SELECT AVG(x) FROM t)
WHERE id IN (SELECT id FROM u)
WHERE EXISTS (SELECT 1 FROM u WHERE u.t_id = t.id)
q1 UNION q2        -- no repeats
q1 UNION ALL q2    -- keep all
q1 INTERSECT q2   q1 EXCEPT q2

CTEs

WITH step1 AS (
  SELECT ... ),
step2 AS (
  SELECT ... FROM step1 )
SELECT * FROM step2;
WITH RECURSIVE t(n) AS (
  SELECT 1 UNION ALL SELECT n + 1 FROM t WHERE n < 5)
SELECT n FROM t;

Window functions

SUM(x) OVER (ORDER BY d)             -- running total
ROW_NUMBER() OVER (PARTITION BY g ORDER BY x DESC)
RANK()  DENSE_RANK()  NTILE(4)
LAG(x) OVER (ORDER BY d)   LEAD(x) ...
AVG(x) OVER (ORDER BY d
  ROWS BETWEEN 6 PRECEDING AND CURRENT ROW)

Text and numbers

upper(x) lower(x) length(x) trim(x)

Ten classic mistakes

  1. Writing = NULL instead of IS NULL.
  2. Using WHERE for an aggregate condition (use HAVING).
  3. Forgetting ON in a join, which makes a cross join.
  4. Filtering the right table in WHERE after a LEFT JOIN.
  5. Summing after a join to a many table (fan-out).
  6. Integer division giving 3 instead of 3.5.
  7. NOT IN with a NULL in the list.
  8. LIMIT without ORDER BY.
  9. UPDATE or DELETE without a WHERE.
  10. Wrapping an indexed column in a function.
